# Auto Escola Sul da Ilha — Landing Page Premium

Landing page em Next.js 14, TypeScript, Tailwind CSS e Framer Motion.

## Como rodar

```bash
npm install
npm run dev
```

Acessa http://localhost:3000

## Build de produção

```bash
npm run build
npm start
```

## Dados

Todos os dados (WhatsApp, endereço, telefone) estão em `lib/data.ts` — edita lá e o site atualiza automaticamente.

## Deploy

Conecta o GitHub ao Vercel — o site faz deploy automático a cada commit.
